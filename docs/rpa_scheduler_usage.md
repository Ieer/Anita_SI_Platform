# RPA 调度中心历史入口

本文仅解释旧版路由和文档的去向，不再描述当前任务功能。当前实现已迁移到统一任务中心；不要依据历史文档中的甘特图补时、全天监听带、自动重试或 Windows 导入流程执行维护操作。

旧路由 `/rpa_/scheduler` 和 `/rpa_/windows_scheduler` 保留兼容跳转。当前页面、数据边界、权限、运行状态、迁移和隔离演示请以[任务中心指南](task_center.md)为准。

| 旧内容 | 当前说明 |
| --- | --- |
| 任务概览、平台任务、运行日志 | 见[任务中心指南](task_center.md)及[任务配置说明](task.md) |
| Windows 原生任务 | 独立于 APScheduler；平台不会自动导入、停用或双向同步，见[Windows 任务说明](windows_scheduler.md) |
| `tools/task_transformer` 的旧导入参数 | 不作为当前任务中心的迁移流程；执行前必须以仓库中的脚本 `--help` 和当前指南复核 |
| 失败任务自动重跑 | 当前系统不自动重试未知或失败运行；未知结果须人工核实 |

当前概览默认展示未来 24 小时计划，可切换实际运行和 7/30 天范围。图表不虚构运行时长；未知状态单独展示。所有真实维护、任务恢复和 Windows 原生操作都应在隔离演示之外单独评估并确认。
